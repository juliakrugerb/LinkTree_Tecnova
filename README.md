# LinkTree Tecnova

Página de links do Grupo Tecnova (Tecnova Energia + Sul Engenharia e Sistemas).

Página em `index.html` (fontes e estilos embutidos). Logos na pasta `img/`:

- `img/sul-logo.png` — logo completa Sul Engenharia e Sistemas (rodapé)
- `img/sul-simbolo.png` — símbolo Sul (topo e botão do site Sul)
- `img/tecnova-logo.png` — logo Tecnova (rodapé)
- `img/tecnova-simbolo.png` — símbolo Tecnova (botão do site Tecnova)

Para trocar uma logo, substitua o arquivo mantendo o mesmo nome. As logos são brancas com fundo transparente.

## Publicar (GitHub Pages)
1. Envie `index.html` e a pasta `img/` para a raiz da branch `main`.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
3. Endereço: https://juliakrugerb.github.io/LinkTree_Tecnova/
